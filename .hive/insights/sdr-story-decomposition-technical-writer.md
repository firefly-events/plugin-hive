# SDR Story Decomposition Insight

When a decomposition task targets structured YAML rather than human-readable
story prose, the useful part of the story-writing skill is its insistence on
testable acceptance criteria and explicit scope boundaries; the repo-local YAML
schema must still override the skill's section format. For this epic, each story
needed a negative/default criterion because the locked design decisions preserve
default `.pHive` behavior and several intentional literal `.pHive` paths.
